# XRecorder 0.1.0

Native Flutter Android UI baseline from the supplied Stitch ScreenFlow designs.

```sh
flutter pub get
flutter run -d <android-device-id>
```

Uses bundled mock media and Manrope. UI preferences last for the current session.
Capture, playback, editing, export, sharing, subscriptions, and native overlays are not implemented.

```sh
flutter analyze
flutter test
```
