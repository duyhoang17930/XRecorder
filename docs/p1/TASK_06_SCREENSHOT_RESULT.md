- Pipeline hiện hữu: `screenshot` trên capture channel → fresh system consent → foreground CaptureService → native delay 3s → một ImageReader/VirtualDisplay → RGBA Bitmap → PNG → pending MediaOutput → commit → completed/output URI → onSaved/Media Library. Delay dùng deadline Task 05, không Flutter timer. Screenshot không dùng encoder audio/video.
- Regression xác minh từ source: validator track MP4 bổ sung ở Task 04 bị chèn cả vào nhánh PNG và đọc descriptor video null; PNG luôn thất bại trước commit. Đã bỏ validator video **chỉ ở nhánh ảnh**, thay bằng decode bounds/MIME/kích thước PNG từ file vừa ghi (rewind descriptor) trước commit. Video finalizer giữ byte-for-byte so với đầu Task 06.
- Buffer: kiểm width/height, RGBA pixelStride=4, rowStride, kích thước dữ liệu và overflow trước tạo Bitmap/output. Đóng gói từng hàng bỏ padding, không yêu cầu padding của hàng cuối (copy nguyên padded bitmap trước đây có thể buffer-underflow). Không sửa/bịa nội dung pixel, không bypass protected screen hoặc cố loại vùng đen bằng crop. Chỉ bỏ row padding ngoài ảnh.
- Lifecycle: callback muộn kiểm ending/session trước acquire; acquire/handoff lỗi đi vào failed/cleanup, Image đóng nếu worker chưa nhận. Image.use/Bitmap.recycle và release ImageReader/VD/projection giữ flow hiện có. Thêm xử lý thiếu bộ nhớ ở init/handoff; worker đã có catch OOM. Null frame vẫn đợi callback với timeout 10s, không Saved giả.

- Delay/Cancel: giữ 3s theo sản phẩm; Cancel trước frame hủy callback, release/abort, idle, không output/Saved. Khi frame đã giao worker và finalizer sở hữu output, cancel vẫn trả too_late theo contract Task 02, không báo hủy thành công rồi lưu. Stop/cancel trong consent và duplicate request giữ guards hiện có.
